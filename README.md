## 一、这个项目在解决什么问题

一个常见的误区是：把 `open` / `close` / `high` / `low` 直接喂进模型，试图让模型"学出"股票强弱。

**这在数学上不成立。** 绝对价格不具备横向可比性：

| 股票 | 某日收盘价 | 含义 |
|---|---|---|
| 某白酒股 | 1,299 元 | 不是因为它"强"，而是因为它的股本结构决定了价格尺子不同 |
| 某银行股 | 2.25 元 | 不是因为它"弱"，同理 |

价格水平是一个**由面值与拆并决定的尺度量**，而不是一个**刻画强弱的强度量**。两个不同尺子的数直接比大小，
比较结果几乎完全被"这把尺子有多长"支配，与股票本身的强弱无关。

**正确做法**：把一切绝对量转换为**无量纲的相对量**，即 compared across stocks at the same timestamp。
本项目全部输入均为收益率、分位数、比率、z-score 这一类横向可比的量。

具体到本工程：

```
原始绝对量                不能直接比          无量纲化后
──────────────────────────────────────────────────────────
close (元)          →     ✗         →  dist_ma20 = close/MA20 - 1
macd (元)           →     ✗         →  macd_dif_ratio = MACD/close
atr (元)            →     ✗         →  atr_ratio = ATR/close
PE / PB / 股息率     →     ✓         →  已是比率，直接可用
成交量 (手)          →     ✗         →  turnover_rate_f（换手率）
```

## 三、方法链路

整个管子分五步，每一步都在解决一个具体的统计陷阱。

```
 ① 无量纲化   ② 去极值+标准化   ③ 因子族正交化   ④ 行业中性化   ⑤ 合成 & 检验
 ─────────────────────────────────────────────────────────────────────────
 原始行情     Winsorize        Gram-Schmidt    行业内去均值     alpha_neutral
 +财务指标    1%/99%           逐步正交        消除风格暴露     ↓
              ↓                ↓              ↓              ┌────────────┐
           截面 z-score      四族互不相关     银行不再挤占      │ IC 检验     │
           clip(-3, 3)                       TOP10            │ 分层回测    │
                                                              └────────────┘
```

### ① 因子族定义（14 个原始指标 → 4 个族）

与其让 14 个指标各投一票（指标多的族天然占优），不如先合并成 4 个**语义清晰、权重相等**的因子族：

| 因子族 | 成员 | 方向 | 经济学含义 |
|---|---|---|---|
| **TrendMomentum** 趋势动量 | `ret_20d` `ret_60d` `dist_ma20` `dist_ma30` `macd_dif_ratio` `boll_pct_b` | +1 | 追涨：近期涨得好 → 继续涨 |
| **Value** 价值 | `ep_ttm` `bp` `dv_ttm` `ps_ttm`(反向) | +1 | 便宜的好公司有安全边际 |
| **LowVol** 低波 | `realized_vol_20d`(反向) `atr_ratio`(反向) | -1 | 低波动异象（low-volatility anomaly） |
| **Reversal** 反转 | `ret_1d`(反向) `ret_5d`(反向) | -1 | 短期反转：跌多的会反弹 |

### ② Winsorize + 截面 z-score

对每个交易日**横截面**单独处理（不是时间序列），保证同一天内可比：

```python
# 1) 截尾去极值：把极端值按分位点压回来
lower, upper = g[col].quantile([0.01, 0.99])
g[col] = g[col].clip(lower, upper)

# 2) 截面标准化：当天所有股票排成一列，减去均值除以标准差
g["z_" + col] = ((g[col] - g[col].mean()) / g[col].std()).clip(-3, 3)
```

**为什么要 clip(-3, 3)**：z-score 对离群值极敏感。一只票当天涨停会产生 z=8 这种值，
它在后续等权合成里会一票压倒全场。截到 ±3 相当于说"我知道你很强，但强到一定程度就不给额外加分了"。

### ③ Gram-Schmidt 逐步正交化（修复的核心）

原始四族打分之间存在严重共线性 ——「趋势动量」与「反转」两族高度耦合（相关性一度达 0.839）。

| 组合 | 原始相关性 |
|---|---|
| 趋势动量 vs 低波 | 高度相关 |
| 趋势动量 vs 反转 | 高度相关 |

后果是：**一个经济含义被重复计了两次票**。四族的方差贡献严重失衡（7.5% / 36.9% / 44.0% / 11.6%），
合成分名义上是四族投票，实际上几乎只由两族决定。

**修复**：按族做 Gram-Schmidt 正交化，让后一个族只贡献 **前一个族解释不了的那部分**：

```python
def gram_schmidt(X):
    """按列顺序逐步正交化：每列减去它在前面所有列张成的空间上的投影"""
    Q = np.zeros_like(X, dtype=float)
    for j in range(X.shape[1]):
        v = X[:, j].astype(float).copy()
        for k in range(j):
            v -= (Q[:, k] @ X[:, j]) * Q[:, k]   # 减去投影分量
        Q[:, j] = v / np.linalg.norm(v)          # 单位化
    return Q
```

**修复效果**

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 四族方差贡献 | 7.5% / 36.9% / 44.0% / 11.6% | **25.0% / 25.0% / 25.0% / 25.0%** |
| 族间相关性矩阵 | 非对角元最高 0.839 | **单位阵** |
| 行业均值标准差 | 0.276 | **0.036**（压缩 86.9%） |
| TOP10 的行业分布 | 6 只银行股扎堆 | **10 个不同行业** |

### ④ 行业中性化

即便做完正交化，某些行业（样本期内主要是银行）在价值/低波族上仍有**系统性偏移**，
导致 TOP10 里塞满同一行业的票 —— 这不是选股能力，这是偷偷押注了一个行业 beta。

```python
df["alpha_neutral"] = ortho_means - df.groupby(["trade_date", "industry"])["ortho_means"].transform("mean")
```

在每个交易日内部，按行业减去行业均值。剩下的才是"这只票比同行业同伴强多少"。

## 四、结果

### 4.1 分层回测（2019-04 起 310 次调仓）

按 `alpha_neutral` 每日分 Q1~Q5 五档，等权持有 5 日。

| 组合 | 最终净值 | 年化收益 | 年化波动 | 夏普 | 最大回撤 | 年化超额 |
|---|---|---|---|---|---|---|
| **Q1 最强** | 2.327 | 14.16% | 18.11% | 0.782 | -22.58% | **+1.56%** |
| Q1（未做行业中性化） | 2.962 | 18.56% | 16.17% | **1.148** | -12.56% | **+5.96%** |
| Q2 | 2.641 | **16.45%** | 18.11% | 0.908 | -15.95% | +3.85% |
| Q3 | 1.772 | 9.38% | 17.41% | 0.539 | -19.46% | -3.22% |
| Q4 | 2.445 | 15.04% | 18.70% | 0.804 | -23.45% | +2.44% |
| **Q5 最弱** | 1.538 | 6.98% | 21.38% | 0.326 | -31.82% | **-5.62%** |
| 基准（等权） | 2.132 | 12.60% | 17.52% | 0.719 | -18.12% | — |
| Q1-Q5 多空 | 1.388 | 5.27% | 12.14% | 0.435 | -17.30% | -7.33% |

**两端区分出来了**：Q1 (14.16%) vs Q5 (6.98%)，年化差 **7.2 个百分点**；
多空组合虽正收益但夏普仅 0.435，且年化超额为负（-7.33%）——多空两边被交易成本和基准分摊吃掉了。

### 4.2 分年表现：**这套东西不是每年都管用**

| 年份 | Q1 | Q2 | Q3 | Q4 | Q5 | 基准 | 结论 |
|---|---|---|---|---|---|---|---|
| 2020 | 50.8% | 60.5% | 35.9% | 63.4% | 54.9% | 53.2% | ❌ 跑输 |
| 2021 | 2.7% | 2.3% | 1.0% | 31.5% | -2.6% | 6.7% | ❌ 明显跑输 |
| 2022 | **-14.0%** | 2.6% | -9.1% | -7.7% | -1.9% | -6.0% | ❌ 大幅跑输 |
| 2023 | 0.7% | 2.7% | 4.1% | -9.7% | **-17.9%** | -4.3% | ✅ 跑赢 |
| 2024 | **29.3%** | 25.9% | 14.9% | 23.8% | 12.7% | 21.4% | ✅ 跑赢 |
| 2025 | **26.4%** | 24.5% | 17.9% | 23.1% | 20.2% | 22.5% | ✅ 跑赢 |
| 2026（至 8/31） | -0.5% | -5.2% | 0.6% | -10.8% | -14.4% | -6.0% | ✅ 跑赢 |

> **诚实地说**：2020–2022 三年连续跑输基准，2023 年后才开始稳定跑赢。
> 因子存在明显的**阶段性失效**，这与"A 股风格切换"的常识一致。任何声称"全天候有效"的
> 单因子都不值得信。

### 4.3 Spearman IC 检验 —— 截面排名 vs 前瞻 20 日收益的秩相关

| 信号 | IC 均值 | IC 标准差 | IR | **t 值** | IC>0 占比 | 判定 |
|---|---|---|---|---|---|---|
| **`ic_o_trdmom`（趋势动量）** | **-0.0240** | 0.213 | -0.113 | **-4.41** | 50.2% | ❌ **显著为负** |
| **`ic_o_val`（价值）** | 0.0680 | 0.264 | 0.258 | **+10.10** | 59.7% | ✅ 最强，显著 |
| **`ic_o_lowvol`（低波）** | 0.0351 | 0.161 | 0.219 | **+8.56** | 59.6% | ✅ 显著 |
| **`ic_o_rev`（反转）** | 0.0003 | 0.145 | 0.002 | **+0.08** | 49.2% | ❌ **完全无效** |
| `ic_neutral`（合成，中性化后） | 0.0206 | 0.120 | 0.172 | +6.74 | 53.0% | ✅ 显著 |

**三个必须说的负面结论：**

1. **趋势动量在这批样本里是负 alpha**。IC = **-0.024，t = -4.41** —— 统计量远超显著性阈值，
   但符号是反的。也就是说，在本轮 2020–2026 的沪深300样本里，**"追近期涨得好的票"是系统性亏钱的**。
   动量因子在 A 股的有效性一直有争议，本样本支持"无效甚至有害"的一侧。

2. **反转族基本是噪声**。IC = 0.0003，t = **0.08**（远低于显著性水平），IC>0 占比 49.2%
   （约等于抛硬币）。这个族可以直接删掉，留着只会稀释信号。

3. **行业中性化降低了组合表现**。中性化后 Q1 年化从 **18.56% 掉到 14.16%**，夏普从 1.148 掉到 0.782。
   原因不难理解：被中性化去掉的那部分正是**行业 beta** —— 样本期内银行等低估值行业整体走强，
   中性化把它当成"风格暴露"剔除了，也连同把这部分收益剔除了。
   **中性化提升的是纯粹度，不是收益率**，这取决于你的目标是"纯净 alpha"还是"能赚钱"。

### 4.4 第四个负面结论：分档不单调

理想的多因子模型应当呈现 **Q1 > Q2 > Q3 > Q4 > Q5** 的漂亮单调。本模型**没有**：

```
年化收益：Q2 (16.45%) > Q4 (15.04%) > Q1 (14.16%) > Q3 (9.38%) > Q5 (6.98%)
                    ↑ Q2、Q4 反而比 Q1 高
```

中间档乱序说明：**合成分对"次优"区间的分辨能力不足**。
只有 Q5（最差的一档）被稳定识别出来了 —— Q5 在 6 年里有 4 年跑输基准，

这一现象的实际含义：这套排序**做排除法（识别该回避的股票）比做精选法（挑出最强的一批）更可靠**。

## 六、如何使用

### 6.1 打开报表（推荐，5 分钟）

1. 安装 [Power BI Desktop](https://powerbi.microsoft.com/desktop/)（免费）
2. 下载本仓库，把 `data/fact_crosssection.csv.gz` **解压**到 `data/` 目录
3. 双击根目录的 **`CSI300XSRank.pbip`**
4. 首次打开会要求设置数据路径。在 Power BI Desktop 里：
   `主页 → 转换数据 → 管理参数 → 编辑 pCsvFolder`，把它改成你本地的 `data/` 目录
   （注意 Windows 路径要用双反斜杠结尾，例如 `C:\\Users\\me\\CSI300XSRank\\data\\`）
5. 点击`刷新`，等待约 30 秒加载 24.8 万行

> 只需改 `pCsvFolder` **一个地方**，8 张表的分区会自动跟着变。这是 PBIP + 参数化分工的标准做法。

### 6.2 跑通全部分析

```bash
pip install -r requirements.txt

# ① 生成截面排名与合成分（含正交化 + 行业中性化）
python scripts/build_ranking.py

# ② IC 检验与分层回测
python scripts/backtest.py

# ③ 生成 Power BI 工程（TMDL + PBIR）
python scripts/build_pbip.py

# ④ 校验工程结构（悬空引用检测、分区路径一致性）
python scripts/validate_pbip.py
```

## 九、这个项目想说明什么

它没有拿出一个年化 40% 的策略。它给出的是一条**可以被质疑、可以被复跑、每一处取舍都说得清理由**的链路：

- 为什么原始价格不能直接用 → §1
- 为什么要截尾和标准化的具体实现 → §3②
- 为什么发现了共线性并怎么修的 → §3③（这是本工程真正有技术含量的地方）
- 哪些因子有效、**哪些无效、哪些符号是反的** → §4.3
- 哪些年份是失效的 → §4.2

> **一个敢写成"趋势动量 IC = -0.024，t = -4.41"的仓库，比一个声称年化 40% 的仓库可信得多。**
